CSV Check 1.0.0 使用文档

一个只读的命令行小工具：运行一条命令，确认成绩表里是否包含 id、name、score 三个必需列名。

Python 3.12+ 无需安装第三方包 不修改原文件 Windows / macOS / Linux

1这是什么工具

CSV Check 是随课程提供的一个 Python 脚本 check.py。它读取一张 CSV 成绩表，检查表头里有没有必需列，再打印一份简短报告。整个过程只读：不打开编辑器、不写回文件、不上传数据。

它会做

  • 读取 UTF-8 编码的 CSV 表头
  • 统计数据行数（不含表头）
  • 列出缺失的必需列
  • 用 PASS / FAIL 给出结论和退出码

它不会做

  • 不修改、不重排你的文件
  • 不校验分数范围或重复 id
  • 不保证导入系统一定成功
  • 不读 .xlsx；1.0.0 也不识别制表符分隔

判定顺序：先确认“读得到”，再确认“列齐全”。任何一步不通过就立刻停下，不会继续往下判断。

2运行前的准备

2.1 需要什么

项目要求怎么确认
Python3.12 或更高版本（3.8 以上一般也能运行）python --version
第三方包无。全部使用 Python 标准库，不需要 pip install—
终端编辑器内置终端，或 Windows PowerShell能输入命令并回车
文件check.py、csvcheck 文件夹、samples 文件夹放在同一层见 2.2 目录结构

2.2 目录要长成这样

在编辑器里打开 01_写作练习 这个文件夹（不是单独打开 check.py），确认结构如下：

01_写作练习
01_写作练习\
├─ check.py            ← 运行入口
├─ csvcheck\           ← 被 check.py 导入的包，必须与它同层
│  ├─ __init__.py
│  └─ __main__.py

实际运行前的工作目录示意，不是命令输出。

check.py 不能单独拷走 它第一行就 from csvcheck import ...。只复制 check.py 到一个新位置会立刻失败：ModuleNotFoundError: No module named 'csvcheck'。搬家时请连 csvcheck 文件夹一起搬。

2.3 确认 Python 可用

在终端里输入版本命令：

Windows PowerShell
PS> python --version
Python 3.12.8

只要能看到 Python 3.x.x 就说明准备好了；后面的示例统一使用 python。

如果提示“不是内部或外部命令”，先试试 py --version 或 python3 --version；哪个能出版本号，就把下文命令里的 python 换成它。

3三步跑起来

  1. 打开课程文件夹

    在编辑器中选“文件 → 打开文件夹”，选中 01_写作练习。左侧资源管理器里应同时看到 check.py、csvcheck、samples 三项。

  2. 新建终端

    菜单“终端 → 新建终端”（快捷键 Ctrl+`）。终端会默认停在这个文件夹，提示符里的路径应以 01_写作练习 结尾。如果路径不对，先执行 cd 01_写作练习。

  3. 运行检查命令

    输入下面这条命令并回车（文件名可以换成任意一个 .csv）：

    Windows PowerShell — 01_写作练习PASS
    PS> python check.py samples/students.csv
CSV Check 1.0.0
File: samples/students.csv
Data rows: 3
Columns: id, name, score
Missing columns: none
Result: PASS
PASS checks column names, not score values.

    实际运行输出（Windows + Python 3.12.8）。输出是纯文本，可直接复制进记录表。

逐行读懂这份报告

输出行含义
CSV Check 1.0.0工具版本号，写文档时照抄这一行最稳妥
File: samples/students.csv实际读取的路径，相对于当前所在目录
Data rows: 3数据记录 3 条，不含表头那一行
Columns: id, name, score从表头读到的全部列名
Missing columns: none必需列一个都不缺；有缺失时会逐个列在这里
Result: PASS结论：必需列齐全
PASS checks column names, not score values.边界提醒：PASS 不代表分数正确

命令跑完只会出现三种结局。先看最后几行，再决定下一步。

PASS — samples/students.csvPASS
PS> python check.py samples/students.csv
CSV Check 1.0.0
File: samples/students.csv
Data rows: 3
Columns: id, name, score
Missing columns: none
Result: PASS
PASS checks column names, not score values.
FAIL — samples/missing-name.csvFAIL
PS> python check.py samples/missing-name.csv
CSV Check 1.0.0
File: samples/missing-name.csv
Data rows: 1
Columns: id, score
Missing columns: name
Result: FAIL
PASS checks column names, not score values.
ERROR — samples/empty.csvERROR
PS> python check.py samples/empty.csv
CSV Check 1.0.0
ERROR: File has no header.
Next step: use a readable UTF-8 file with a header row.
结果出现条件退出码下一步
PASS 能正常读取，且必需列全部存在 0 可以进入下一步流程
FAIL 能读取，但缺少必需列 1 补齐列名，或用 --require 改要求（见第 5 节）
ERROR 空文件、没有表头、表头有空列名或重复、字段数与表头不一致、不是 UTF-8 2 先修源文件，再重新运行
PASS 的边界 PASS 只证明“要求的列名齐全”。它不检查分数范围、不查重复 id，也不代表导入一定成功。写说明文档时，请把这句话和 PASS 一起交代，否则读者会误解。

5换一组必需列

默认要求 id name score。用 --require 可以临时指定别的列，列名写在文件名后面，区分大小写：

--require 只要求两列PASS
PS> python check.py samples/students.csv --require id name
CSV Check 1.0.0
File: samples/students.csv
Data rows: 3
Columns: id, name, score
Missing columns: none
Result: PASS
PASS checks column names, not score values.
--require 要求一个不存在的列FAIL
PS> python check.py samples/students.csv --require id name class
CSV Check 1.0.0
File: samples/students.csv
Data rows: 3
Columns: id, name, score
Missing columns: class
Result: FAIL
PASS checks column names, not score values.

注意第二条：文件本身没问题，是要求变了，所以结论变成 FAIL。这也是为什么文档里必须写清楚“这次检查要求哪些列”。

6常见问题

提示 can't open file 'check.py'：找不到脚本

当前目录不在 01_写作练习。先用 pwd（PowerShell 用 Get-Location）看路径，再 cd 到包含 check.py 的文件夹；或重新“打开文件夹”。不要靠反复重装 Python 解决。

提示 python 不是内部或外部命令

这台机器上的命令名可能是 py 或 python3。先用 py --version／python3 --version 试出可用的那个，再把命令的第一个词替换掉，后面保持不变。

检查 .tsv 时结果为 FAIL，列名看起来“都在”

1.0.0 只按逗号切分，制表符分隔的整行会被当成一个列名，于是 Missing columns 会把三列都列出来。处理办法：先另存为逗号分隔的 CSV；或者使用 1.1.0 版本并加 --delimiter \t。

终端里冒出一段红色的 PowerShell 配置报错

那是本机终端加载 profile 脚本被策略拦截，与 CSV Check 无关。只要上面几行报告正常打印，结果就是有效的。

PASS 了，但表里的分数明显不对

符合预期。工具只比对列名。分数核对属于数据校验，不在本工具范围内。
